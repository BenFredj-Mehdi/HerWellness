# Pregnancy Month Guidance (Static)

Simple static website that displays common pregnancy problems and suggested solutions by month (1–9).

Main features

- Default language: Tunisian Arabic (dialect). Users can switch to English via the language selector.
- If the user doesn't find a matching problem, a suggestion/link to a chatbot page is shown (chatbot is a placeholder).

How to use

- Open `index.html` in a browser (double-click or serve with a static server).
- Choose the pregnancy month and click the button to view problems and suggested actions.

Notes

- The chatbot page is currently a placeholder at `chatbot.html` — you can add the real chatbot later.
- This project is a prototype: content should be reviewed by medical professionals before publishing as medical advice.
